📐 Math Breakdown

Step 0

Initial Prediction:

F₀(x) = mean(y) = average of all target values

Sabse pehle simple average se start karo — ye hamari "rough sculpture" hai

Step 1

Calculate Residuals:

rᵢ = yᵢ − F(xᵢ) = actual − predicted

Residual = kitna galat hai current prediction. Canvas pe RED arrows dekh!

Step 2

Fit Tree on Residuals:

hₜ(x) = DecisionTree.fit(X, residuals)

Naya tree RESIDUALS ko predict karta hai — original values ko NAHI!

Step 3

Update Prediction:

F_new(x) = F_old(x) + η × hₜ(x)

Purani prediction + learning_rate × tree ka fix = better prediction!

📐 Classification Math

Step 0

Initial Log-Odds:

F₀ = log(p / (1−p)) = log(count₁ / count₀)

Start with log-odds of positive class ratio

Step 1

Convert to Probability:

p = σ(F) = 1 / (1 + e⁻ᶠ)

Sigmoid function maps log-odds → probability [0,1]

Step 2

Pseudo-Residuals:

rᵢ = yᵢ − pᵢ = actual_label − predicted_prob

Class 1 ke liye: r = 1 − p (positive). Class 0 ke liye: r = 0 − p (negative)

Step 3

Leaf Output (special for classification):

leaf_value = Σrᵢ / Σ(pᵢ × (1−pᵢ))

Ye hai gradient / hessian — 2nd order optimization!

Step 4

Update:

F_new = F_old + η × leaf_value
p_new = σ(F_new)

Probabilities shift closer to correct labels!

📐 Key Formulas

Similarity = G² / (H + λ)
Gain = Sim_Left + Sim_Right − Sim_Parent − γ
Optimal Weight w* = −G / (H + λ)

For MSE: gᵢ = ŷᵢ − yᵢ (= −residual), hᵢ = 1

🛡️ Regularization Effect — λ and γ

λ (Lambda) — L2 Regularization

λ = 1

λ badhao → leaf weights CHHOTE hote hain → smoother predictions → less overfit

γ (Gamma) — Pruning Penalty

γ = 0

γ badhao → minimum gain threshold BADHA → kam splits → simpler tree

📐 AdaBoost Math

Formula 1

Weighted Error:

ε = Σ wᵢ × I(yᵢ ≠ ŷᵢ)

Galat predictions ka weighted sum

Formula 2

Learner Importance:

α = ½ × ln((1−ε) / ε)

Low error → high alpha → zyada credible teacher

Formula 3

Weight Update:

Misclassified: w × e^(+α) ↑
Correct: w × e^(−α) ↓

Galat → weight UP (bigger circle). Sahi → weight DOWN (smaller circle)

Formula 4

Final Prediction:

F(x) = sign(Σ αₜ × hₜ(x))

Weighted vote of all weak learners

Algorithm — Grand Comparison

Saare boosting algorithms ek jagah — kab kaunsa use karna hai! 🏆

🎪

AdaBoost

The OG (1995)
  • Approach: Sample reweighting
  • Loss: Exponential
  • Base: Decision Stumps
  • Speed: 🐢 Slow
  • Regularization: ❌ None
  • Categorical: ❌ Manual
  • Missing Values: ❌ Manual
Best for: Simple problems, interpretability
📈

Gradient Boosting

The Framework (1999)
  • Approach: Fit residuals (gradients)
  • Loss: Any differentiable
  • Optimization: 1st order only
  • Speed: 🐢 Slow
  • Regularization: ⚠️ Basic
  • Categorical: ❌ Manual
  • Missing Values: ❌ Manual
Best for: Understanding the theory
⚡

XGBoost

The Champion (2014)
  • Approach: Regularized GB
  • Optimization: 2nd order (Hessian)
  • Tree Growth: Level-wise
  • Speed: 🏃 Fast
  • Regularization: ✅ L1 + L2 + γ
  • Categorical: ❌ Manual
  • Missing Values: ✅ Auto
Best for: Competitions, interpretability (SHAP)
🏎️

LightGBM

Speed Demon (2017)
  • Approach: GB + 3 tricks
  • Tree Growth: Leaf-wise 🌿
  • Tricks: GOSS + EFB + Histogram
  • Speed: ⚡ Fastest
  • Regularization: ✅ L1 + L2
  • Categorical: ✅ Native
  • Missing Values: ✅ Auto
Best for: Large datasets, speed-critical apps
🐱

CatBoost

Category King (2017)
  • Approach: Ordered Boosting
  • Trees: Symmetric (Oblivious)
  • Encoding: Ordered Target Stats
  • Speed: 🏃 Fast
  • Regularization: ✅ L2 + Ordered
  • Categorical: ✅✅ Best native
  • Missing Values: ✅ Auto
Best for: Categorical-heavy data, minimal tuning
